# Business associate agreement materials

These are unsigned drafting aids for a future US HIPAA engagement. They are not evidence that any vendor has signed a BAA or that a clinic/provider is eligible for HIPAA processing.

Use the [checklist](BAA_CHECKLIST.md) to determine applicability and required provisions; use the [drafting template](BAA_TEMPLATE.md) to collect counsel-approved terms. HIPAA does not apply automatically to a Bangladesh clinic or a health-themed demo. EU processor agreements and Bangladesh processor/transfer requirements need separate assessment.

Start with [HHS business-associate contract guidance](https://www.hhs.gov/hipaa/for-professionals/covered-entities/sample-business-associate-agreement-provisions/index.html). HHS sample provisions do not replace a complete engagement-specific agreement. Store executed contracts in restricted document storage outside the public repository; publish only scrubbed agreement status when authorized.
