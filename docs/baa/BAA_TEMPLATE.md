# BAA drafting worksheet

**Unsigned draft for qualified legal review — 2026-09-24.** This worksheet does not claim contractual completeness or compliance. Do not execute it as a finished agreement. Use current [HHS sample provisions](https://www.hhs.gov/hipaa/for-professionals/covered-entities/sample-business-associate-agreement-provisions/index.html) and engagement-specific counsel drafting.

| Clause group | Terms to complete before execution |
|---|---|
| Parties and scope | Real covered entity/business associate, service agreement, effective date and processing description |
| Definitions | Incorporate applicable HIPAA definitions and resolve consistency with the main contract |
| Permitted uses | Specific purposes, minimum necessary where applicable and prohibited secondary use |
| Safeguards | Applicable administrative, physical and technical obligations; shared responsibilities |
| Incidents | Contacts, notice content, cooperation and negotiated response deadlines that support legal duties |
| Subcontractors | Required downstream terms and process for changes |
| Rights assistance | Access, amendment, accounting and other applicable assistance with workable deadlines |
| Oversight | Required regulatory access and agreed assurance/evidence process |
| Covered entity duties | Relevant notice, authorization and restriction changes |
| Breach/remedies | Termination rights and appropriate cure/remedy conditions |
| End of service | Return/destruction, infeasibility exceptions, continuing protections and export format |
| Commercial terms | Liability, indemnity, governing law, priority between agreements and dispute provisions |
| Execution | Authorized signatories, dates and restricted storage location |

Do not insert fictional clinic details or assume generic 24/72-hour reporting and 15-business-day access terms are statutory BAA deadlines. Negotiate operational deadlines against applicable law and customer obligations. Security representations must match actual provider evidence. Keep all completed values and signatures outside this public worksheet.
