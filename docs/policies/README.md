# Proposed operating policies

These are **draft templates**, updated 2026-09-24. They describe responsibilities and evidence for a future clinical operator. No effective date, named officer, signed contract, paid backup plan or completed training program is asserted. Adopt them only after jurisdiction, vendor and implementation review.

| [Data classification](DATA_CLASSIFICATION.md) | Handling rules for public, personal, clinical and secret data |
| [Privacy impact](PRIVACY_IMPACT_ASSESSMENT.md) | Data-flow and rights risk assessment |
| [Risk assessment](RISK_ASSESSMENT.md) | Risk owners, treatment and residual risk |
