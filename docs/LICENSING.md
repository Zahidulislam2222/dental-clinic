# Licensing and third-party rights

No project-wide open-source license file is present in this publication. Publishing source does not itself grant a general commercial reuse license. The owner must choose licensing terms before the project is described as open source. See [GitHub licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).

Dependencies retain their own licenses; review the actual installed versions and distribution obligations. [Media sources](MEDIA-SOURCES.md) records image provenance. A recorded source URL is not, by itself, proof of permission for every commercial use, model/property release, trademark use or sublicensing.

Before a real clinic launch, verify rights for images, clinician names, testimonials, logos, translations and clinical copy. Replace fictional identities and claims with approved, substantiated content. Document owner permission and third-party notices privately where sensitive, and publish required attribution. Do not select an MIT/Apache license or assign third-party rights without the owner's decision.
